# SSW Gestão: app instalável

Atalho instalável (PWA) do **SSW Gestão**, o sistema interno da SSW Medicina e Segurança do Trabalho.

Este repositório tem só a tela de abertura e o ícone. O sistema e todos os dados ficam no Google Workspace da SSW. Aqui não há nenhuma informação de clientes.

**Como funciona:** na primeira vez, o app pede o link do sistema (o link do Apps Script que termina em `/exec`). Depois disso, abre direto.

**Para trocar o link:** abra o endereço do app com `?configurar` no final.
